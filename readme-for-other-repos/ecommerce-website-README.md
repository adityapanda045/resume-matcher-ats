> A fully functional e-commerce frontend built with pure HTML, CSS, and JavaScript — no frameworks, no dependencies.

---

## ✨ Features

- 🛒 **Shopping Cart** — Add, remove, and update product quantities
- 🎨 **Responsive Design** — Works on desktop, tablet, and mobile
- 🖼️ **Product Listings** — Clean product cards with pricing
- ⚡ **Pure Vanilla JS** — No external dependencies, fast and lightweight
- 🎯 **Clean UI** — Intuitive user experience

---

## 🛠️ Tech Stack

| Technology | Purpose |

| **CSS3** | Styling, animations, responsive layout |
| **JavaScript** | Cart logic, interactivity, DOM manipulation |
